抵死瞒生

dǐ sǐ mán shēng
Literal: "resist death, conceal life"
Home › Method › 抵死瞒生

📖 Meaning

To exhaust all one's wits and try every conceivable means to achieve a goal. It describes someone scheming desperately and using every trick available. Equivalent to the variant form '抵死漫生'.

📜 Origin Story

This idiom originates from the Ming Dynasty anonymous play 'Pang Lüe Si Jun' (庞掠四郡), Act 3. The original line reads: 'I have arranged a plan to escape and benefit myself, which exactly matches this desperate scheming strategy.' It depicts the use of exhaustive cunning and every possible scheme to accomplish one's objectives. The term is synonymous with the variant '抵死漫生'.

💡 Example Usage

他抵死瞒生地算计了半天，到头来却落得一场空。

He schemed desperately using every trick in the book, only to end up with nothing in the end.
